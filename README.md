How to use: 

1. Put all dds files you want to 'fix' into the same folder as the script/executable
2. Run the script/executable
3. The programm will generate new .dds files with '_fixed' added to the name

Currently only compatible with ASTC formats. Non-compatible formats are skipped.

If you want to view or convert the .dds files Switch Toolbox is a good place to start
