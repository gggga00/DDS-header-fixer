# How to use: 

0. Download MR_DDS_fixer

If you don't want to run the python script you can download an excutable from the releases.

1. Put all dds files you want to 'fix' into the same folder as the script/executable
2. Run the script/executable
3. The programm will generate a new folder "/fixed" which will contain all the fixed dds files

Currently only compatible with ASTC formats. Non-compatible formats are skipped.
